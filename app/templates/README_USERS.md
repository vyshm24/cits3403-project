# Travel Blog User Guide

## Overview
This is a travel blog website where users can share their travel experiences, create itineraries, and browse other users' travel stories.

## Features
- Create and manage travel itineraries
- Browse and search for travel itineraries
- Like and comment on itineraries
- Upload profile pictures and cover images
- Responsive design for all devices

## Getting Started
To get started with the travel blog, simply navigate to the website and create an account. Once you're logged in, you can start creating and sharing your travel itineraries with the community.

## Pages
- Home Page: Main landing page of webpab with basic introductoey information and starting point for navigation through app
- Login Page: page to login to existing account
- Register Page: page to create a new account
- Profile Page: page to view user profile which contains information about countries visited and displays all users created itineraries. This page also allows the customisation of user information
- Create Itinerary Page: page including sophisticated form to a new itinerary. 
- View Itinerary Page: page to view an existing itinerary in detail
- Search Page: page to search for itineraries

## Running Tests

Run Unit Test: `python -m unittest discover -s tests unit -v`
Run System Tests: `python -m unittest discover -s tests/system -v`
Run Server: `python run.py`
